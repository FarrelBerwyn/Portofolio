Selected Project

PELNI Digital — Smart Maritime Ticketing & Services App

Maritime App Indonesia Inter-Island Connectivity

PELNI Digital is a mobile application designed to improve the accessibility and efficiency of maritime transportation services in Indonesia. As an archipelagic nation, Indonesia relies heavily on inter-island connectivity to support public mobility and economic growth.

The Challenge

Limited access to maritime transportation services — particularly in terms of ticket bookings and travel information — remains a critical challenge for many Indonesians living across the archipelago.

Developer

Built by Farrel Berwyn, combining full-stack development with AI integrations to create a scalable maritime services platform.

Key Features

Core capabilities developed for the PELNI Digital platform:

01

Smart Ticketing System

Streamlined ticket booking experience with real-time availability, seat selection, and digital payment integration for seamless maritime travel.

02

Backend APIs & Data Pipelines

Robust backend architecture with real-time data pipelines handling schedule updates, booking transactions, and fleet management across Indonesia's maritime routes.

03

AI-Powered Predictive Maintenance

Machine learning integrations for predictive maintenance and route optimization, ensuring fleet reliability and operational efficiency.

04

Scalable Cloud Deployment

Container orchestration with Docker and Kubernetes for high-availability deployment, handling traffic spikes during peak travel seasons.

Tech Stack

React Node.js Python TensorFlow Docker Kubernetes REST API
