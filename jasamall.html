Selected Project

Jasamall — One-Stop AI Services

🤖
10+ AI Agents Intelligent Ecosystem

Jasamall adalah sebuah aplikasi "One-Stop Solution" untuk layanan profesional berbasis ekosistem AI Chatbot spesialis. Aplikasi ini berfungsi sebagai aggregator pintar yang memudahkan akses ke berbagai keahlian terintegrasi.

Konsep & Alur Kerja

Alih-alih mencari di direktori manual, pengguna dapat langsung berinteraksi dengan asisten AI terspesialisasi (seperti konsultan hukum, asisten penulisan, panduan kesehatan, pembuat kode, dan analis bisnis) yang memiliki kepribadian dan basis pengetahuan unik.

Pengembang

Dikembangkan secara mandiri oleh Farrel Berwyn, dengan fokus integrasi NLP, manajemen sesi, basis pengetahuan dinamis, dan orkestrasi chatbot terpusat.

Fitur Utama

Layanan multi-agen terintegrasi untuk menangani tugas-tugas kompleks dengan orkestrasi cerdas.

01

Chatbot Ecosystem

Agen AI khusus untuk setiap kategori keahlian yang dilengkapi instruksi khusus (system prompts) dan knowledge base mendalam.

02

Central Coordinator Routing

Model pengarah cerdas yang otomatis menganalisis intensi input pengguna dan mengarahkan percakapan ke bot spesialis terbaik.

03

Vector Search & RAG

Integrasi pencarian berbasis vektor (Retrieval-Augmented Generation) untuk menjamin jawaban chatbot tetap faktual, presisi, dan aman.

04

Unified Chat Dashboard

Satu antarmuka terpadu yang mulus untuk beralih antar asisten ahli tanpa harus kehilangan context dari alur kerja utama pengguna.

Detail Teknis

  • Integrasi Data: Penyimpanan basis pengetahuan dinamis berbasis embedding dan pencarian teks semantik.
  • Desain: Responsif dan dioptimalkan untuk performa tinggi dengan response time minimal.

Tech Stack

Python LangChain OpenAI API Vector DB React Node.js
