Selected Project

SIAGA — AI Emergency Navigation System

SIAGA is an AI-based emergency navigation system that combines reinforcement learning with IoT traffic simulations to generate optimal ambulance routes in real time.

What I built

  • Reinforcement Learning agent to optimize routing under dynamic traffic conditions.
  • IoT simulation environment to model real-world traffic patterns and constraints.
  • Real-time decision modeling to select fastest emergency routes.

Impact

Simulated results show ~25% reduction in response time and more robust routing decisions under uncertainty.

Tech Stack

Python • TensorFlow / PyTorch • OpenCV • Reinforcement Learning • Docker • IoT Simulation
