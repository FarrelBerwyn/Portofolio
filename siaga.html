Selected Project

SIAGA — AI Emergency Navigation System

🚑
~25% Faster Emergency Response Time

SIAGA is an AI-based emergency navigation system that combines reinforcement learning with IoT traffic simulations to generate optimal ambulance routes in real time.

Impact

Simulated results show approximately 25% reduction in response time and more robust routing decisions under uncertainty, potentially saving lives in critical emergency situations.

Developer

Built by Farrel Berwyn, combining expertise in AI/ML, reinforcement learning, and IoT simulation environments.

What I Built

Core components developed for the SIAGA emergency navigation system:

01

Reinforcement Learning Agent

Custom RL agent to optimize ambulance routing under dynamic traffic conditions, adapting in real-time to changing road situations and congestion patterns.

02

IoT Traffic Simulation

Comprehensive simulation environment to model real-world traffic patterns and constraints, creating realistic scenarios for training and evaluating the RL agent.

03

Real-Time Decision Modeling

Intelligent decision system to select the fastest emergency routes by processing live traffic data, road conditions, and historical performance metrics.

Tech Stack

Python TensorFlow PyTorch OpenCV Reinforcement Learning Docker IoT Simulation
